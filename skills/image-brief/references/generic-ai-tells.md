# Generic AI tells

The `Evita` line is the strongest lever in the brief. Vague exclusions do nothing; name the ornament.

## How to build the list

1. Generate one draft with no exclusions.
2. Ask the model: *"How would you describe the typeface and the decorative elements around the text?"*
3. The answer is vocabulary: `thin horizontal rules`, `small radial rays`, `rounded pill shapes`, `cursive script`, `dry brush strokes`.
4. Move every element the answer names into `Evita`.

Ask for one category at a time. Changing five things at once makes it impossible to tell what improved.

## Universal exclusions

Present, destructive, invisible on the reference poster:

- bunting, bulb garlands, confetti
- branches and flowers, stars and moon
- brush-stroke bands behind text, brush underlining
- distressed texture, dry brushwork
- sparkles and glows, speed lines, decorative rays
- thin horizontal rules, thin diagonal rules
- cursive script, generic geometric sans with wide tracking
- smiling stock-photo people, group celebrations
- detail callout circles, annotation arrows, floating icons
- invented slogans or lemas the user did not write

## Conflicts to resolve before generating

| Profile or style | Conflict |
| --- | --- |
| Art Nouveau | `curved lines` exclusion — the style requires them |
| Blueprint / cyanotype | `dark backgrounds` exclusion |
| Risograph | `no texture` exclusion — the texture is the technique |
| Pixel art | `no halftone dots` exclusion |
| Grunge typography | `no distressed texture` exclusion |

When the exclusion contradicts the chosen style, drop the exclusion and say so in the brief.

## Product additions

For any image derived from a reference photo, also exclude: dark backgrounds, gradients, detail callout circles, annotations, icons, slogans, invented parts, and any change to the shape, color or logo of the product.
