# Three-layer style model

`Estilo` carries up to three independent layers. Naming one layer from each is what separates a specific image from an average one.

| Layer | Directs | Examples |
| --- | --- | --- |
| Design and layout | how information is organized | Swiss, Art Deco, Constructivist, Bauhaus |
| Illustration or art movement | how figures are represented | pixel art, cubism, surrealism, pop art |
| Technique or finish | what the reproduction looks like | screenprint, risograph, cyanotype |

Fill all three when the brief calls for it. Naming one from each layer is what separates a specific image from an average one; an unnamed layer falls back to the model's default and drifts. Change only one layer between iterations. That is the cheapest way to compare styles.

## Rules

- Do not stack names for their own sake. A composition, a palette and a finish beat a list of five movements.
- Not every label fits every brief. If the label is unfamiliar, explain its visual traits first and let the user choose.
- Iterate with a single instruction: *"Regenerate with style X. Keep the specifications, the exact text and the Evita line."*
